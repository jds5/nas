## 鉴权与运行配置

- 核对 v4.2.6 百度驱动只接受 OAuth refresh_token，不接受 Rust 的 BDUSS/STOKEN Cookie 作为直接配置。
- 用现有 Cookie 访问百度官方授权端点，提交授权返回 `not_login`，未成功转换。未修改 Rust 登录态。
- 告知用户 OpenList 文档的 ES 文件浏览器 OAuth 客户端及 basic/netdisk 权限后，用户在官方页面完成授权并提供一次性授权码。
- NAS 直接向 `openapi.baidu.com` 换取令牌，挂载 `/百度网盘`。关闭在线令牌刷新中转，直接走百度官方刷新接口。
- guest 禁用、sign_all=true；FTP、SFTP、S3 均关闭。只发布 LAN 5244，不发布 IPv6/wildcard，不连接 NPM 网络。
- 挂载 `/SSD下载` 至 `/opt/nas/cache/openlist/downloads`。所有状态、临时目录、部署包位于 `/opt/nas/cache/openlist`，属 `/dev/nvme0n1p3` ext4 SSD；restic 明确排除 `/opt/nas/cache`，nas-config Git 同样忽略。
- download/transfer/copy 配置 workers=1、task_persistant=true；数据库对应三个任务线程设置也改为 1，避免仅修改配置文件而被数据库设置覆盖。
- 开放 LAN 前以 SQLite backup API 保存数据库及 config.json 到权限受限目录，未复制下载数据。
- Docker Hub 获取过慢、GHCR 拒绝；通过已有本机代理下载官方发布包，SHA-256 校验后以现有固定摘要 Alpine 镜像构建。详情见应用 README。
