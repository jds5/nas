## 回滚

需要回滚时，以 `yao` 执行以下命令。使用安装器同一把锁避免并发更新；只影响之后启动的 CLI，不停止现有会话：

```bash
(
  set -eu
  flock -x 9
  release_root=/home/yao/.codex/packages/standalone
  rollback_link="$release_root/.rollback-current.$$"
  test -x "$release_root/releases/0.158.0-x86_64-unknown-linux-musl/bin/codex"
  ln -s "$release_root/releases/0.158.0-x86_64-unknown-linux-musl" "$rollback_link"
  mv -Tf "$rollback_link" "$release_root/current"
  cp /home/yao/.nas-maintenance-backups/codex-update-20261004/auto-update-version.before "$release_root/auto-update-version"
  /home/yao/.local/bin/codex --version
) 9>/home/yao/.codex/packages/standalone/install.lock
```

回滚保留原有自动更新策略，不等于永久锁定旧版本。回滚命令本轮未执行。
