## CVE-2026-123158：OpenSSH 密码绕过

| 项目 | 内容 |
| --- | --- |
| 漏洞 | sshd 在 musl libc、不用 PAM 时，musl 的 `crypt()` 对超过 256 字节的密码返回 `*`，与无密码账号在 shadow 中的 `*` 相同，导致 256–1024 字符的任意密码可登录部分账号。11-05 公开，CVSS 3.1 为 8.1（高危），修复版本 OpenSSH 10.6p2；Alpine 各分支已发布修复包 |
| 影响条件 | ①libc 为 musl；②sshd 不用 PAM；③开启密码登录。glibc 发行版（Debian、Ubuntu、RHEL）和使用 PAM 的 sshd 不受影响 |
| 本机宿主机 | Debian 13，`openssh-server 1:10.0p1-7+deb13u4`，sshd 链接 glibc（`libc.so.6`，libc6 2.41）；`sshd_config` 为 `UsePAM yes`、`PasswordAuthentication no`、`KbdInteractiveAuthentication no`、`PermitRootLogin no`，`sshd_config.d` 为空。**三个条件都不满足** |
| 容器 | 逐个检查 43 个运行容器：Alpine 容器里都没有 `/usr/sbin/sshd`；`beszel-agent` 里看到的 sshd 进程是宿主机的（该容器 `pid=host`，容器内没有 sshd 文件）；`npm`、`nas_web_terminal` 等只有 ssh 客户端 |
| 结论 | **不受影响，不需要修复。** Debian 安全追踪暂无该 CVE 条目（glibc 平台不涉及）。以后 Debian 发布 OpenSSH 更新时按常规由 unattended-upgrades 安装即可 |
