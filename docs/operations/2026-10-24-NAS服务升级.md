## 备份与回滚

私有目录（不入 Git，约 17 GiB，权限 700）：

```text
/home/yao/.nas-maintenance-backups/upgrade-20261024/
```

- 每个容器一个子目录：升级前 `inspect.json`、Compose 原文、停止后 `docker cp` 导出的数据（`mount-*.tar`）及 SHA-256。旧镜像统一保留为 `nas-rollback/<容器名>:upgrade-20261024`。
- Immich：停写后的逻辑备份 `immich.dump`、PostgreSQL / Valkey 物理备份；逻辑备份已在 `--network none` 的隔离容器中恢复，数量与生产一致，测试容器和卷已删除。
- Stock PostgreSQL：逻辑备份 `stock.dump`（645 MB）与停库后物理备份（9.6 GB）。
- 未备份：照片、媒体、下载内容，以及 Jellyfin 缓存 / 转码目录。

回滚单个容器（先不带 `--confirm` 预演，打印恢复计划）：

```bash
python3 /home/yao/.nas-maintenance-backups/upgrade-20261024/rollback.py jellyfin
python3 /home/yao/.nas-maintenance-backups/upgrade-20261024/rollback.py jellyfin --confirm
```

脚本校验备份摘要后停止容器，将当前数据目录改名为 `.post-upgrade-时间戳` 保留，恢复旧数据并把 Compose 镜像改为回滚标签后重建。升级后新增的数据不会合并。Immich 需对 `immich_server`、`immich_machine_learning`、`immich_postgres`、`immich_redis` 一起执行；Stock Playwright 需浏览器与两个客户端一起回滚，并恢复 Stock 仓库中的版本固定。已对 Seerr、Immich 数据库、Stock 数据库和百度网关做预演，**未在生产执行真实回滚**。

NPM 缓解的回滚：删除 `/opt/nas/npm/data/nginx/custom/http.conf`，再执行 `docker exec npm nginx -s reload`。OpenResty 发布含 1.30.6 / 1.31.7 修复的版本、NPM 跟进后，应升级 NPM，届时可以移除这项缓解。
