## 需要用户处理或授权

1. **SSH 暴力破解**：建议在路由器上限制 2257 端口的来源，或部署 fail2ban（需要 sudo）。目前虽然无法登录进来，但 MaxStartups 丢弃连接时，**你自己的连接也可能被一起拒绝**。
2. **OneDrive 异地备份**：先清理云端配额或调整保留策略，再处理限流；同时**恢复 Kuma 中 `restic-onedrive` 的监控**，否则失败不会告警。
3. **确认身份**：SSH 来源 122.192.14.208、116.147.252.5；Immich iPhone 用户 223.65.30.61。
4. **Kavita API Key 出现在 NPM 访问日志里**：Tachiyomi 把 key 放在 URL 中，日志会随 restic 一起备份。风险低，可以考虑轮换。
5. 内核重启和 Docker 升级需要你提供 sudo 密码，并确定维护时间。
