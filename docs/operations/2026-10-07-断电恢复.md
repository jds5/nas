## 回滚与遗留

若需撤销本次网络修复，可依次执行以下命令；会再次中断对应服务，不应在正常恢复后执行：

```bash
docker network disconnect nas-baidupcs-web_default nas-baidupcs-web-gateway-1
docker network disconnect nas-openlist_default nas-openlist-openlist-1
docker network disconnect nas-gopeed_default nas-gopeed-gopeed-1
docker network disconnect expose-net npm
```

如需撤销本次启动，可执行 `docker stop nas_web_terminal nas-baidupcs-web-gateway-1 nas-openlist-openlist-1 nas-gopeed-gopeed-1 npm`，会中断终端、下载入口及全部 HTTPS 反代。

`sudo -n true` 仍需要密码，未执行系统级开机依赖修复、完整内核日志与 SMART 检查。再次断电可能复现 LAN 地址和 tmux 目录就绪顺序问题；后续需在执行环境授予相应 sudo 权限后实施持久修复。不将服务恢复视为断电前 tmux 任务或全部数据完整性已恢复。
