# NAS 网页终端开发与内部部署（2026-09-29）

## 需求与现场

用户要求参考 `~/code/home` 实现整个页面由 Cloudflare Access 保护的在线 tmux 终端，入口按用户后续要求改为 `https://rokano.org/terminal`，沿用 home 的允许邮箱。现场实际参考仓库为 `/home/yao/code/homeland`，tmux 会话名为 `home`；没有修改 Homeland 代码或服务。新应用在 [apps/web-terminal](../../apps/web-terminal/README.md)，规划及开发前写入面审计在 [PLAN.md](../../apps/web-terminal/PLAN.md)。

核验环境：NAS `ynas`，宿主用户 UID/GID 1000，tmux 3.5a，socket `/tmp/tmux-1000/default`，`exit-unattached off`。NPM 当前宿主映射 8443→443、LAN 81 管理端口，现有通配符证书覆盖 `*.rokano.org`。没有使用历史配置直接修改路由。

## 实际完成

- 实现完整网页终端、会话列表、手机快捷键、中文输入框、粘贴与显式回车、全屏和手动重连。连接已有 tmux，不解析 Codex 协议，支持终端初始化选项。
- HTML、资源、API、WebSocket 均由 jose RS256 验签；校验 issuer、独立 Audience、exp/nbf、已签名邮箱白名单。缺少配置全部 403。POST 校验精确 Origin 与 CSRF header，WS 校验 Origin 和身份绑定的一次性 30 秒票据。连接受 JWT 到期及最长 15 分钟限制。
- tmux client 不踢其他客户端，不覆盖宿主 session 环境；服务端队列内再次核对 PID/创建时间。断开仅结束该 client。测试发现 socket ctime 随 tmux 连接/断开变化，已改用 inode/birthtime 等稳定身份，避免正常重连被拒绝。
- 添加专用 Worker 与 NPM 配置模板及回滚步骤；Worker 覆盖回源 Secret，保留 Origin/JWT/WS 子协议。同步统一 Access 手册的整站私有应用要求。
- 部署镜像 `nas-web-terminal:0.1.0`、容器 `nas_web_terminal`，独立网络 `nas-terminal-front` **当前只有该容器**；未连接 NPM，无宿主端口映射。非 root 1000:1000、只读 rootfs、capabilities 全部移除、no-new-privileges、内存/PID/CPU 限额，仅挂载 tmux socket 目录。
- 本地 `.env` 权限 600，继承 home 的 Team Domain，独立 AUD 和邮箱白名单仍为空，**生产容器处于拒绝所有请求状态**。没有把 home 的 Audience 复制给新应用。

## 0.2.0：PC 性能、图片与输入优化

按用户顺序完成四项优化并更新运行容器到 `nas-web-terminal:0.2.0`：

- **性能**：连接前只查询目标 session，避免重复遍历会话列表；本机相同 15 次只读采样，校验中位从 41.0 ms 降到 5.4 ms，样本最大值从 53.6 ms 降到 7.8 ms。这只表示服务器本地校验耗时，不等于公网端到端延迟。切换复用原 WebSocket，无需重做 POST 票据和连接握手；每次切换重新核对目标，epoch 隔离旧输入/输出，连接期限不延长。初始 PTY 使用实际页面尺寸，去掉连接后的全列表刷新；输出 ACK 按 32 KiB/40 ms 合并、resize 按动画帧去重，背压保留。未修改 tmux window-size 策略。
- **图片**：支持选择、拖入、Ctrl+V 粘贴图片，预览与移除；每消息最多 4 张 PNG/JPEG/WebP、合计 20 MiB。原始图片流式存储到专用 `/home/yao/.nas-web-uploads`，目录 700、随机文件名/文件 600，容器挂载至 `/uploads`。没有开放图片下载 URL，没有挂载整个家目录。总配额 512 MiB；成功文件保留供历史对话读取，不自动删除。图片绑定已验签用户、会话身份与 pane，提交前核对前台仍是 Codex，生成类似安卓端的本地路径说明；非 Codex 和混合 `/`、`!` 命令拒绝。确认超时保留草稿、提示核对，不自动重发。
- **输入**：PC 专用，移除粘贴、键盘及 Esc/Tab/方向键等移动按键栏；Enter 发送、Ctrl+J 插入换行，中文输入法确认不发送。草稿与待发图片按会话保存于页面内存。默认输入高度从 39 px 增至 156 px，可向上拖高。

验证：15 组 Node 测试通过；1440×900 和 1920×1080 Chromium 自动化验证了单 WebSocket 多次切换、独立草稿、Enter/Ctrl+J/IME、图片选择/剪贴板/拖放、断开重连；持续输出 60,000 行仍保持连接。再次将同版本 NPM 的代理放在隔离测试容器前，验证超过 2 MiB 图片可上传和提交；测试 Codex 使用同名前台接收进程，仅用于检查协议与图片路径提交，不声称该模拟程序完成了真实 Codex 看图推理。测试未向生产会话发送按键，也未读取 `.env`。真实用户经 Cloudflare 的上传体验待刷新后验证。

部署：旧镜像 `nas-web-terminal:0.1.0` 保留；上一版 Compose 和 NPM 终端模板备份在 `~/.nas-maintenance-backups/web-terminal-0.2.0-20260929/`。通过 NPM 模型更新标记块，增加终端子树的 20 MiB 请求上限、流式转发、请求超时和较短的 Docker DNS 缓存；原 Advanced 备份 `/data/nas-terminal-routing-1790619718114.json`。`nginx -t`、重载和容器健康检查通过；未认证终端/上传路由为 403，原 `/home/` 200、`/stock/` 403 保持不变。上传目录挂载核验 UID 1000、权限 700；无宿主端口映射。

## 0.3.0：普通终端与临时 SSH

已部署 `nas-web-terminal:0.3.0`。非 Codex tmux 窗格默认聚焦原生终端、收起大输入框，完整支持命令行按键与全屏程序；可以手动展开输入框。后台每 1.5 秒检查前台程序，Codex 显示消息输入，退出后切回终端。新增“＋ 临时 SSH”直接登录 NAS 的 yao shell，无需 tmux；断开/切换关闭该 SSH，重连创建新 shell。临时 SSH 中不启用需要 tmux 前台验证的图片发送。

现场确认 bridge 到 NAS SSH 被现有防火墙阻断，未放行任何网络。采用独立 `nas_web_ssh_transport` 非 root 容器，host 网络只用于访问 `127.0.0.1:22`，仅监听权限 600 的 `/home/yao/.nas-web-ssh/transport/ssh.sock`，无 TCP 监听。Web 容器保持专用 bridge，通过只读挂载的专用 SSH key 和固定主机公钥连接；转接容器只挂 transport 子目录，无私钥挂载。authorized_keys 增加独立、仅 loopback 来源、禁止转发且允许 PTY 的 key。首次尝试用户级 socket service 时发现无 linger 权限，已撤下此次新建的两个 unit，最终只用 Compose 持久化，不留下用户级转接服务。

验证：17 项 Node 测试全部通过，包括独立 SSH 路由、无 tmux 时建连、鉴权/Origin 拒绝、断开及到期释放子进程；1440×900、1920×1080 Chromium 验证普通终端直接输入、临时 SSH 按钮与断开提示、原有草稿/图片/快捷键/流控/切换功能。浏览器测试使用隔离 shell double，不挂 NAS 凭据。另使用真实独立 SSH key 经生产转接容器登录 NAS，核对用户 yao、TMUX 为空、Ctrl+C 中断，断开后从宿主 PID 检查确认登录 shell 已消失。未向既有生产 tmux 会话发送输入。两容器 running/healthy，匿名 SSH 接口 403。未读取 .env 或用户现有私钥；真实公网 Access 登录交互仍由用户刷新页面验收。

鉴权仍最多 15 分钟，临时 SSH 到期会关闭；正常主动断线立即关闭，网络中断经 5 秒心跳检测。显式 nohup/disown 或另起 tmux 的后台任务遵循正常 SSH 保活语义。

重要文件备份在 `~/.nas-maintenance-backups/web-terminal-0.3.0-20260929/`，包括变更前 authorized_keys 和 Compose；旧镜像 0.2.0 保留。回滚执行：


撤销网页专用 SSH 登录可执行以下命令，保留其他密钥和并发变更：

```bash

p = Path.home() / '.ssh/authorized_keys'
p.write_text(''.join(line for line in p.read_text().splitlines(keepends=True)
                     if not line.rstrip().endswith(' nas-web-terminal-ephemeral')))
PY
```
