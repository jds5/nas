第一季实际为 H.264、1280×720；第二季实际为 H.264、1024×576。Sonarr 对纯数字源文件名的初始质量识别与实测不符，导入后将第一季修正为 HDTV-720p、第二季修正为 SDTV 分类，并通过 Sonarr 重命名；SDTV 是其质量分类名称，不表示把视频转成 480p。未转码，画面分辨率与文件内容保持不变；来源类型没有独立核验，不能据分类名断言发行来源。

跨 SSD / 媒体盘采用“Sonarr 复制导入 → SHA-256 对比 → 移除源文件”完成移动，不在校验前删除原件。源目录之外的文件不纳入操作。

## Jellyfin 元数据

该库当前关闭联网元数据提供器，Sonarr 的 NFO 输出也未启用。本次只为该系列生成本地 `tvshow.nfo`、每集同名 `.nfo`，填写《仁医》标题、Sonarr 已有的提供器 ID、季集编号、首播日期及剧情；复制 Sonarr 已有海报等图片，不修改整个媒体库的刮削设置。Jellyfin 初次扫描仍沿用目录名 JIN，因此通过该剧条目的元数据 API 将显示名修正为“仁医”并锁定 Name 字段，保留原名 JIN 和正确的提供器 ID。

本地元数据文件名及唯一标识依据 [Jellyfin NFO 文档](https://jellyfin.org/docs/general/server/metadata/nfo/)。手动导入使用 [Sonarr ManualImportCommand](https://github.com/Sonarr/Sonarr/blob/develop/src/NzbDrone.Core/MediaFiles/EpisodeImport/Manual/ManualImportCommand.cs) 和 [ManualImportFile](https://github.com/Sonarr/Sonarr/blob/develop/src/NzbDrone.Core/MediaFiles/EpisodeImport/Manual/ManualImportFile.cs) 对应的 API 字段，并在本机实际验证。
