日期：2026-10-07。设备：`ynas`，Debian，`192.168.50.33`。

用户在首轮升级后授权“除了宿主机，全部升级”，因此本轮包含此前保留的 Immich、Uptime Kuma 和 Stock 依赖。Docker、containerd、Compose 及宿主机其他软件包未升级。

## 版本与实施

本轮处理 6 个项目，涉及 **9 个运行容器**（包含 Immich 机器学习和两个 Playwright 客户端）。

| 项目 | 升级前 → 升级后 | 实施方式 |
| --- | --- | --- |
| Immich server / machine learning | 3.2.2 → 3.2.4 | 官方镜像；机器学习保留 OpenVINO 版本、模型缓存和核显设备 |
| Immich PostgreSQL | 14.19 → 14.24 | 基于原 Immich 专用镜像构建补丁镜像；未跨 PostgreSQL 大版本 |
| Immich Valkey | 9.0.3 → 9.1.2 | 官方镜像，保留数据目录 |
| Uptime Kuma | 1.23.17 → 2.5.5 | 完整备份后执行官方 v1 → v2 数据迁移 |
| Stock Redis | 7.4.11 → 8.10.2 | 官方 Alpine 镜像，保留 AOF 数据、密码配置和 loopback 端口 |
| Stock Playwright | 1.48.0 → 1.63.0 | 同步更新浏览器服务、collector 和 research-worker 的 Python 客户端 |

原本停止的 `stock_scheduler` 没有启动；其 Compose 镜像及后续构建依赖已同步为新客户端版本。没有改动照片、媒体文件或研究数据的存储路径，没有新增或释放端口。

## 两项需要保留的维护方式

### PostgreSQL 补丁镜像

Immich 3.2.4 官方 Compose 仍固定旧的专用数据库镜像。为升级 PostgreSQL 补丁而保留现有向量扩展，本轮新增生产构建文件：

```text
/opt/nas/immich/Dockerfile.postgres14-patch
```

固定 PostgreSQL 包版本为 `14.24-1.pgdg12+2`；生成镜像 `nas-immich-postgres:14.24-vectorchord0.4.3-pgvectors0.2.0`。生产 Compose 使用本地镜像并设置 `pull_policy: never`。以后该本地镜像需要重建时，使用 Dockerfile 中的构建命令；不要替换为不含扩展的普通 PostgreSQL 镜像。

### Playwright 服务端与客户端

生产代码仓库：`/home/yao/code/stock`。新增 `deploy/Dockerfile.playwright` 在构建期安装固定的 JS 包，容器启动不再临时联网执行 `npx` 下载；`deploy/Dockerfile.playwright-client-patch` 可在保留的运行镜像上仅更新 Python 客户端。

本轮基于升级前运行镜像构建客户端，未重新构建或部署工作区中其他尚未提交的应用代码。标准 collector requirements 和 scheduler 基础镜像也已同步，避免后续重建回到 1.48.0。相关本地镜像设为 `pull_policy: never`。

Stock 仓库原有大量未提交/暂存改动。本轮通过独立 Git index 只提交已有服务的升级差异、requirements 和 Dockerfile，并逐项确认原有无关暂存内容保持不变。`research-worker` 整段服务定义原本尚未提交，它的现场镜像更新仍随该原有工作区改动保留，没有将整段无关工作混入维护提交。

## 备份与回滚

私有备份目录（不入 Git）：

```text
/home/yao/.nas-maintenance-backups/apps-phase2-20261007/
```

包括原容器信息和 Compose、约 641 MiB 的停止写入后物理备份（Kuma、Immich PostgreSQL/Valkey、Stock Redis）、两份 Immich 逻辑备份、SHA256 清单、迁移和功能验证记录。旧镜像保留为 `nas-rollback/<容器名>:phase2-20261007`。照片原文件和模型缓存未复制，也未迁移或删除。

回滚必须同时考虑镜像和升级后的数据库格式。私有目录提供 `rollback.py`，依赖 Python 3、PyYAML、Docker/Compose 和数据父目录写权限：

```bash
python3 /home/yao/.nas-maintenance-backups/apps-phase2-20261007/rollback.py immich
python3 /home/yao/.nas-maintenance-backups/apps-phase2-20261007/rollback.py uptime-kuma
python3 /home/yao/.nas-maintenance-backups/apps-phase2-20261007/rollback.py stock-redis
python3 /home/yao/.nas-maintenance-backups/apps-phase2-20261007/rollback.py stock-playwright
```

每次只运行需要恢复的组。脚本核验备份摘要，停止该组，将升级后数据保留为 `.post-upgrade-时间戳`，再恢复旧数据和镜像；浏览器组同时恢复服务端命令及两个客户端镜像。升级后新增数据不会自动合并，执行前需要确认回滚时间点；回滚后须复验业务，并相应调整源码依赖固定版本。

回滚脚本已做语法检查，未在生产执行；**PostgreSQL 逻辑备份恢复已在无生产挂载、无发布端口的隔离容器实测通过**，该测试容器及其临时数据卷已清理。
