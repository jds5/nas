## 安装脚本

[install-baidupcs.py](../../scripts/download/install-baidupcs.py) 为本机首次安装使用，依赖 Python 3 标准库、curl、git、findmnt、lsblk、install、sudo 及 GitHub HTTPS 网络。以 `yao` 执行，不要 sudo 整个脚本：

```bash
python3 /home/yao/code/nas/scripts/download/install-baidupcs.py --check
python3 /home/yao/code/nas/scripts/download/install-baidupcs.py
```

脚本使用上游 [v4.0.2 发布包](https://github.com/qjfoidnh/BaiduPCS-Go/releases/tag/v4.0.2)，linux-amd64 zip 的 SHA-256 固定为 `b5f51388b510433668ca22fa5a1cb8840fb4d9725c5edc830554645010a62339`，来源为 [发布资产页](https://github.com/qjfoidnh/BaiduPCS-Go/releases/expanded_assets/v4.0.2)。下载失败或摘要不符即停止，不运行未经校验的程序。

安装前检查设备、排除规则、已有安装；已存在的目标拒绝覆盖，因此不改变旧配置。下载包和首次配置在临时目录准备，仅创建下载目录时调用 sudo，可能要求输入本机 sudo 密码。

| 路径 | 用途 |
| --- | --- |
| `/home/yao/.local/share/baidupcs-go/4.0.2/` | 程序与来源摘要 |
| `/home/yao/.local/bin/BaiduPCS-Go` | 固定配置目录及工作目录的启动入口 |
| `/home/yao/.config/BaiduPCS-Go/` | 配置与未来登录凭据，权限受限，不放入 Git |
| `/opt/nas/cache/baidupcs-downloads/` | 下载数据，所属 yao，权限 700 |

默认单文件线程数及同时下载文件数均设为 1，后续按账号类型和实测调整。不安装后台服务，不开放端口，不创建定时下载或自动备份任务。下载目录虽在 cache 下，不应在未核对下载状态时清理。

脚本安装后输出版本和配置；应核对保存目录再登录。登录参考[上游文档](https://github.com/qjfoidnh/BaiduPCS-Go#登录百度帐号)，Cookie 不粘贴进聊天、项目文件或可记录的 shell 命令行。真实账号登录和下载仍需后续完成。

```bash
/home/yao/.local/bin/BaiduPCS-Go config
/home/yao/.local/bin/BaiduPCS-Go download '/网盘目录/文件名'
```

使用 `--save`、`--saveto` 或修改 `savedir` 会覆盖默认位置，因此正常下载不要使用这些选项。启动入口会先切换到专用下载目录，但不限制用户主动指定其他路径。

## 验证与回滚

本轮 Python 语法检查、`--check` 只读预检通过。没有执行下载包校验、程序启动、配置生成或真实百度下载验收，也没有触发 restic 备份或完整性检查。

首次安装没有替换旧文件。如安装后需要停用，先正常退出正在运行的 BaiduPCS-Go，再执行以下命令移走入口；保留程序、配置和下载数据，不删除数据：

```bash
mv -n /home/yao/.local/bin/BaiduPCS-Go /home/yao/.local/bin/BaiduPCS-Go.disabled
```

恢复入口：

```bash
mv -n /home/yao/.local/bin/BaiduPCS-Go.disabled /home/yao/.local/bin/BaiduPCS-Go
```

安装中途失败可能留下新建目录；脚本拒绝盲目覆盖，重试前核对具体失败步骤及已有目录，不直接删除下载数据或凭据。
