## 〇、TL;DR

1. **先翻光猫底部铭牌**：分清楚是 `F657GV` 还是 `F657GV9`（**两者完全不同**，2024 年江苏/湖南联通新装的多为 F657GV9）。
2. **先打 10010/10000/10086 要超密**：2024–2025 年起运营商普遍上了 OLT 动态密码下发，**几乎所有"默认超密 + 默认工具法"在新固件上都已失效**。客服一通电话给个临时超密的成功率，比折腾两个晚上工具高得多。
3. 客服不给再走技术路：**拔光纤 → 复位 → 默认超密**（成功率取决于固件出厂时间是否 ≤ 2023-09），不成再上 telnet 工具，最后兜底是 **TTL/UART 拆机**。
4. **别忽视一个新现实**：F657GV9 用的 ZX279127S 平台**无法持久化 telnet**，即使开了重启就丢，所以**核心目标是拿到超密改桥接**，不是开 telnet 长期驻留。
5. **拿到超密后第一件事**：登录后台立刻关 **TR-069**，否则运营商一推送配置又给你重置回路由模式 + 改回随机密码。

## 一、必须先做的两件事（不做后面全是瞎忙）

### 1.1 翻铭牌：确认型号和版本

光猫底部贴纸上找以下字段并拍照记录：

| 字段 | 例子 | 意义 |
|------|------|------|
| **Model / 型号** | `ZXHN F657GV9` 还是 `ZXHN F657GV` | **两者破解路径完全不同**，见 § 二 |
| **H/W Version** | V9.0 / V1.x | F657GV9 通常是 V9.0 |
| **S/W Version** | V9.2.0P1T1 / V9.2.0P21T12 | 固件版本号，**判断漏洞窗口的关键** |
| **SN / 设备序列号** | 12 位 | 客服核身用 |
| **MAC / LOID** | — | 拨号绑定 + 部分破解工具需要 |
| **运营商标识** | 中国电信 / 中国联通 / 中国移动 | 决定默认账号 |
| **生产日期** | 2024.07 等 | **2023.09 之后基本告别"无脑工具法"** |

> **南京当地情况**：江苏属电信/联通/移动三大运营商兼有。先确认本机是哪家。

### 1.2 看清当前路由模式 / 拨号配置（防丢配置）

进光猫前台（普通用户）抄下来：

| 项 | 抄什么 |
|---|--------|
| WAN 连接列表 | 每条 WAN 的 **VLAN ID**（VID）、协议（PPPoE / IPoE）、服务类型（INTERNET/VOIP/IPTV）|
| PPPoE 拨号账号 | 至少要知道账号；密码若不显示则需问客服或抓包 |
| IPTV 配置 | 如果有 IPTV，记下 IGMP / VLAN |
| 子网 / DHCP 段 | 改桥接后会变路由器接管，先记参考 |

**目的**：万一破解过程把光猫搞挂了，客服来人重做也能给出现场参数；改桥接时 AX86U 的 WAN 配置也直接照抄。

## 二、F657GV vs F657GV9 关键差异（不可混为一谈）

调研中**大量教程把这两者混着写**，必须先区分：

| 维度 | F657GV（老版） | F657GV9（V9 平台，2024 新版） |
|------|---------------|------------------------------|
| 硬件平台 | 早期方案（部分文章未明） | **ZX279127S**（ARM A9 单核 + 1G 内存） |
| 主销售年份 | ~2020–2022 | 2024–2025 大规模铺货（江苏联通 2024-07 起、湖南联通 2024 已普及） |
| 默认管理页 | 192.168.1.1 | **192.168.1.1/cu.html**（联通版） |
| WiFi | 部分型号自带 | **不带 WiFi**，纯 4 千兆 LAN |
| Telnet 可持久化 | 部分可（看固件） | **❌ 不可**（ZX279127S 平台限制） |
| 工具法成功率（2025） | 旧固件可行；新固件多失效 | 出厂 ≤ 2023-09 高，2024 后出厂大量失败 |
| 拆机 TTL 难度 | 中（参考 F663N 类似方案） | 已有教程（恩山 8390401，2024-08） |

> 用户当前文档（NAS 搭建进度 § 4.2）只写了"光猫型号 ZTE F657GV"，**强烈建议下次翻铭牌时确认尾号是否带 9**，因为路径完全不同。下文按"两条线"并行陈述，遇到分叉处明确标注。

## 三、时效性鉴别（哪些"教程"已经过时，不要照搬）

> 本节是这份调研最值钱的部分 —— 中文圈光猫破解文章鱼龙混杂，时间戳常常隐藏。

### 3.1 已经"基本失效"的方法（仍然能搜到但慎用）

| 方法 | 原理 | 失效原因 |
|------|------|---------|
| **默认超管密码"通刷"** | telecomadmin/nE7jA%5m（电信）、CUAdmin/CUAdmin（联通）、CMCCAdmin/aDm8H%MdA（移动） | OLT 动态密码下发：光猫上线后运营商立即推送随机超密，**默认超密只在工厂态 + 未联网那一瞬间有效** |
| **直接访问 `/telnet.gch` 或 `/cgi-bin/...` 接口开 Telnet** | 早期固件未做认证 | 2022 后基本全堵 |
| **改 MAC 为 `00:07:29:55:35:57` 配合 zteOnu 老版本** | 工厂模式后门 | 仅对 **2023-09 之前出厂**的固件有效；新固件 + OLT 升级后的设备直接 `WebRecv Fail` |
| **U 盘备份 config.bin → 老版 ztecfg 解** | 旧 AES key 固定 | 新机种密钥/格式已变；Jarvis 在线服务（jarvisw.com/onutools）覆盖到 F663NV9/F673AV9 但**最近更新停留在 2023-03**，F657GV9 不在已知支持列表 |
| **CSDN 2018–2021 高赞文章里"输 /cu.html 直接进路由"** | 部分老固件未隔离 | 现在 cu.html 也要超密才能进高级配置 |

**通用警示**：凡是文章**没写日期**、**没写适用固件版本号**、**对所有型号一招通吃**的，**99% 是抄旧文不更新**。优先信 2024-08 之后发布、明确写了固件 V9.x 实测的帖子（恩山论坛 8390401、Inkflow 2024-02、知乎 7384412244）。

### 3.2 仍然有效但有窗口期的方法

| 方法 | 适用 | 窗口条件 |
|------|------|---------|
| **拔光纤 + 复位 + 默认超密** | 出厂态固件 ≤ 2023-09 | 光纤未插的几分钟内进后台改密 |
| **Septrum101 系工具（factorymode_crack / zteOnu / TelnetONU 1.6）** | F657GV9 中较老固件 | 必须拔光纤 + 出厂态；新固件返 `WebRecv Fail` |
| **U 盘备份配置 → 自建本地 ztecfg 解** | 已能用普通用户/超管登录的前提 | 需先有进入备份功能的账号；这其实是"已经拿到密码之后的导出"，不是从零破解 |

### 3.3 一直有效但成本高的方法

| 方法 | 成本 | 适用 |
|------|------|------|
| **打运营商客服要超密**（10010/10000/10086 → 报"宽带超管密码"）| 5–30 分钟电话 + 偶尔需上门 | 全运营商、全机型 |
| **TTL/UART 拆机 + uboot 读 NAND** | USB-TTL + 焊接 + 1–2 小时 | F657GV9 实测可行（恩山 8390401，2024-08）|
| **闲鱼"光猫破解服务"** | ¥30–80 | 江浙沪有大量代破解卖家，远程或寄回 |

## 四、推荐执行顺序（按性价比从高到低）

> **黄金原则**：每动一步前先想"如果失败、设备变砖、运营商查到，怎么办"。光猫**只要硬件不焊死**几乎都能由运营商重置救活，但**桥接拨号信息一定要先抄下来**。

### 方法 A：打客服要临时超密 ⭐ 性价比最高

| 项 | 内容 |
|---|------|
| 适用 | 任意运营商 / 任意固件 |
| 操作 | 打 10010（联通）/ 10000（电信）/ 10086（移动），话术："**光猫需要改桥接接自己的路由器**，请给一个临时超管密码" |
| 成功率 | 联通最宽松（很多客服直接给），电信中等（看大区，江苏需上报），移动较严（部分大区不给） |
| 风险 | 客服可能上报后台 → OLT 重新下发动态超密，临时密码当场就过期。**拿到密码后立刻动手改桥接 + 关 TR-069**，整套流程压缩在 30 分钟内 |
| 备选话术 | "光猫无线信号弱，要关闭 WiFi 自己接 AP" / "智能家居要做端口转发，麻烦给个超密"。**别说"破解" / "改 root"**，会被拒 |

### 方法 B：拔光纤 + 复位 + 默认超密

| 项 | 内容 |
|---|------|
| 适用 | 固件 ≤ 2023-09 的设备；联通 F657GV9 验证可行（Inkflow 2024-02 实测） |
| 操作 | ① 拔光纤接头（橙色细管）<br>② 长按 RESET 10 秒，等灯闪复位完成<br>③ 浏览器开 `http://192.168.1.1`（联通 F657GV9 走 `/cu.html`）<br>④ 选"管理员账户"，输 **默认超密**：<br>　　• 联通：`CUAdmin` / `CUAdmin`<br>　　• 电信：`telecomadmin` / `nE7jA%5m`<br>　　• 移动：`CMCCAdmin` / `aDm8H%MdA`<br>⑤ 进高级管理 → **先关 TR-069 / 自动升级 / 强制推送**<br>⑥ 修改超管密码（自定义记下来）<br>⑦ 改桥接模式（基本配置 → 上行线路 → WAN 连接 → 修改为桥接，VLAN ID 抄 § 1.2）<br>⑧ 最后插回光纤 |
| 成功率 | 老固件高（联通 V9.2.0P1T1 阶段可用）；2024 年后期新固件大量失败 |
| 风险 | 失败后再次插光纤，OLT 会自动恢复配置；最坏情况 5 分钟即可恢复 |
| 时间窗 | **光纤未插的整段时间都是窗口期，不要急** |

### 方法 C：Jarvis / Septrum101 工具临时 telnet

> 前提条件和方法 B 几乎一样（拔光纤 + 出厂态），但绕开"必须知道初始超密"那一步。

| 项 | 内容 |
|---|------|
| 工具 | `factorymode_crack.exe`（Jarvis 整合版）/ `zteOnu.exe` / `TelnetONU 1.6` |
| 操作 | ① 拔光纤 + 复位（同方法 B 前两步）<br>② 电脑插光猫 LAN 口，IP 段 192.168.1.x<br>③ 命令行：`factorymode_crack.exe -l xxx open -i 192.168.1.1`<br>④ 成功返回 `user=root pass=Zte521`（或类似一次性凭证）<br>⑤ telnet 192.168.1.1 登录 → 执行：<br>　　`sendcmd 1 DB set DevAuthInfo 0 Pass <你的新密码>`<br>　　`sendcmd 1 DB save`<br>⑥ 浏览器用新密码登 cu.html 改桥接 |
| 成功率 | 固件 ≤ 2023-09：~80%；2024 之后：经常 `WebRecv Fail` |
| F657GV9 特别说明 | **telnet 临时拿到 shell 也无法把 telnet 服务持久化**（ZX279127S 平台限制），但**改超密这一条命令仍然有效**，所以仍然值得一试 |
| 风险 | 多数工具是非官方破解版，建议在沙箱 / 隔离 VM 跑，别给主机装 |
| 备注 | 工具来源：恩山论坛、Jarvis 博客（jarvisw.com）、Chiphell 等。**别从来路不明的 QQ 群下载**，挂木马常见 |

### 方法 D：UART/TTL 拆机硬核法（兜底）

| 项 | 内容 |
|---|------|
| 适用 | 上面全失败、又不想出闲鱼钱时 |
| 硬件 | USB-TTL 转换器（CH340 / PL2303，¥10）、杜邦线、电烙铁 / 镊子（部分主板有针脚可直接夹） |
| 步骤（参考恩山 8390401，2024-08 实测）| ① 拆壳，找主板 4–5 个对齐焊点（TX/RX/GND/VCC）<br>② 用万用表测出 GND 与 VCC，确认电平 3.3V<br>③ TTL 接 115200-8-N-1，开机看 uboot 启动信息<br>④ F657GV9 在"Starting kernel..."之后**没有 shell 提示符**，必须在 uboot 阶段中断进入<br>⑤ uboot 命令：`nand read 0x42000000 0x800000 0x800000`（读 usercfg 分区）<br>⑥ `md.b 0x42000000 <len>` 把内存 hex 打印到串口，**慢，~2.88 KB/s**<br>⑦ 抄下来 → Python 脚本转回二进制 → `binwalk -e` 提取根文件系统<br>⑧ 找 `db_user_cfg.xml`，用 `routepassview` 或自己解 AES（多数 V9 平台 key 为 16 字节 0x00） |
| 时间 | 全程 1–3 小时，第一次会卡在焊接 |
| 风险 | 焊错可能短路烧主板（小概率）；**不影响正常使用**（uboot 操作只读 NAND） |
| 优点 | **不依赖运营商固件版本**，原理级方法，几乎永远有效 |

### 方法 E：闲鱼代破解（懒人路）

| 项 | 内容 |
|---|------|
| 价格 | 远程（向日葵 / TeamViewer）¥30–50；寄回处理 ¥50–100（含来回快递自付） |
| 风险 | ① 隐私 —— 卖家会看到你内网信息（有 NAS 的话注意先停敏感服务/换密码）<br>② 留后门 —— 部分卖家会偷加 telnet 帐号或 SSH key（事后用 `sendcmd 1 DB show` 查 AuthInfo 表，并修改所有密码）<br>③ 售后 —— 运营商一推送配置又改回去，卖家不负责回血 |
| 适用 | 实在不想折腾 / 不会拆机 / 已经被工具搞失败一次的场景 |

## 五、拿到超密后必做的"加固六步"（别白破解了）

> 这一节比破解本身更重要 —— **不做加固，OLT 一推送你前面全白干**。

| # | 操作 | 路径 / 命令 | 为什么 |
|---|------|-----------|--------|
| 1 | **关 TR-069 远程管理** | 高级管理 → TR069/CWMP → URL 改为 `http://127.0.0.1` 或直接禁用 | 阻止 ACS 服务器推送配置 / 改密 |
| 2 | **关自动固件升级** | 设备管理 → 升级管理 → 关闭"自动升级" | 防止 OLT 推新固件把方法 B/C 漏洞补掉 |
| 3 | **关强制推送配置** | 设备管理 → 强制推送 / 插件管理 → 全关 | 防止运营商把后台改回 |
| 4 | **改超管密码为强随机** | 高级管理 → 用户管理 | 别留 CUAdmin 给下一波扫描器 |
| 5 | **关掉 UPnP** | 应用 → UPnP → 关闭 | CGNAT 下无意义，反而是攻击面 |
| 6 | **U 盘备份配置** | 设备管理 → 配置管理 → 备份 | 保存到 NAS `/opt/nas/_archive/onu-config-2026-05.cfg`，万一被重置可恢复 |

**额外建议**：
- **关 WiFi 模块**（如果光猫带 WiFi）：让 AX86U 唯一负责无线，避免双 AP 干扰
- **关 IPv6 自动配置**（若你不用 v6）：CGNAT 下用 v6 反而能拿到公网入口，**但前提是想清楚要不要暴露**
- **拨号信息抄写一遍**：账号 + 密码 + VID + 协议，截图存档

## 六、改桥接后的连锁影响（提前预判）

> 这部分关联到 [NAS 网络架构设计](NAS网络架构设计.md) 的最终落地。

| 项 | 改桥接前 | 改桥接后 |
|---|---------|---------|
| 公网 IPv4 | CGNAT，不可入 | 联通家宽走 PPPoE，**大概率拿到公网 IPv4**（南京江苏联通近两年宽松，电信偶尔下发 CGNAT） |
| 端口转发 | 不可（光猫无法配置） | AX86U 直接配，**80/443 仍可能被联通封**，但 8080/8443/19132 等高位端口基本可用 |
| AX86U 角色 | LAN 模式（双 NAT 下游） | **WAN 拨号** + 路由 + DHCP 服务器（IP 从 192.168.50.1/24 改回原网段或保持） |
| 性能 | 双 NAT 增加 1ms 左右延迟 | 单层 NAT，对游戏 / Tailscale 直连有帮助 |
| Tailscale 直连 | 受双 NAT 影响，DERP 概率高 | **改桥接后多数家庭能直连**，对体验提升明显（NAS 网络架构 § 4.8 的 DERP 顾虑大幅缓解） |
| Cloudflare Tunnel | 双 NAT 下也能跑（出站连接） | 没影响，本来就是出站 |
| IPTV | 光猫处理 | **可能失效**（如有 IPTV 服务），需要 AX86U 配置 IGMP Proxy + 单线复用 |

**实操建议**：改桥接当天预留 2–3 小时，按这个顺序：
1. 光猫超密拿下 + 加固六步 → 备份配置
2. AX86U 改 WAN 拨号模式（先填上一节抄下来的 PPPoE 账号密码）
3. 光猫改桥接保存重启
4. **验证**：AX86U WAN 拿到公网 IP（看是不是 100.x / 10.x 私有段，是的话仍是 CGNAT；是 117.x / 222.x 类公网段就成）
5. NAS Tailscale 重连，跑 `tailscale status` 看是否变 `direct` 不再走 DERP
6. 跑 [NAS 网络架构设计 § 八 执行顺序](NAS网络架构设计.md#九执行顺序建议按风险排序) 的第 5 步起（域名/CF Tunnel）

## 七、风险与退路

| 风险 | 概率 | 退路 |
|------|------|------|
| 设备配置被搞乱无法上网 | 中 | 长按 RESET 30 秒恢复出厂，重新 PPPoE 拨号（账号密码靠 § 1.2 抄底）|
| 改桥接后没拿到公网 IP | 中（看运营商策略）| 回退路由模式即可，方法 A/B 知道超密的话再改回来 5 分钟 |
| 运营商发现"非法改桥接"上门 | 极低 | 实际江浙沪基本无人管，最坏情况就是上门复位，无罚款 |
| 工具带木马 | 中（非官方破解版常见）| 用 VirusTotal 扫一次；最好开 VM/沙箱跑 |
| 焊接搞坏光猫 | 低 | 闲鱼买同型号备用机（¥80–150 二手）；运营商上门换机不收钱（说"坏了"即可）|
| 破解后被 OLT 重置 | 高（不加固的话）| 严格执行 § 五 加固六步；备份的 .cfg 文件可一键恢复 |

**最坏剧本**：所有方法都失败 + 焊接搞坏 + 运营商不给超密 → 闲鱼 ¥80 一个二手 F657GV9 出厂态，找代破解 ¥30 远程，**总成本 ¥110，2 小时解决**。可以接受。
