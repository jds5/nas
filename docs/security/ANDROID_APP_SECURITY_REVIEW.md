# 项目安全诊断：Android 0.4.1

日期：2026-09-17（包含 0.2.0 基线及 0.3.0 / 0.3.1 / 0.4.0 / 0.4.1 增量复核）。范围为仓库当前源码、Android/SSH/tmux/Python 桥接、LAN 下载服务、媒体脚本和既有网络待办；包含本机隔离测试和当前会话只读关联。不是生产 NAS 渗透测试、全依赖漏洞扫描或手机取证。本轮未改动生产 SSH、NPM、防火墙和路由器。

## 结论与已修正项

未在所审查的 App 路径发现可绕过主机指纹或把普通聊天文字拼成 SSH shell 命令的路径。不能据此认定整个 NAS 安全：旧凭据失效、真实公网暴露范围和手机端运行验证仍缺证据。

| 项目 | 处理与证据 |
| --- | --- |
| 凭据文件读取可能在检查大小之前大量分配内存 | 改成读取过程中限制 128 KiB；GCM 完整性校验、Keystore 和 noBackup 存储保留。未在 Android 设备上实测密钥硬件属性 |
| 会话误关联、混入隐含上下文 | 只沿选定 pane 的进程树找到 Codex 打开的 rollout；多目标直接拒绝，不按 cwd/mtime 猜测。不遍历 Codex 子代理；只提取公开消息类型和明确 `user_shell` 结果 |
| 粘贴后误按确认或发送到新会话 | 发送前核对 pane/server PID、存活、前台命令、进程/文件绑定及空草稿；粘贴后再次核对绑定与输入画面。菜单/已有草稿拒绝；不确定结果断开且不自动重试 |
| 超大数据及资源耗尽 | 请求、tmux 输出、JSONL 读取窗口、消息长度/数量、手机消息缓存、技能目录扫描和 SSH 操作均有限制。读取损坏记录失败时隐藏原异常，文件句柄及时释放 |
| 历史分页边界丢消息 | 使用完整记录边界和被裁剪消息的位置继续翻页；测试覆盖窗口截断、数量/字节上限、半写入 JSONL |

## 已检查的边界

- **身份与传输**：仅 publickey，强制 SHA256 主机指纹；不自动信任新指纹，不启用弱算法兼容，不加载任意 SSH 配置/代理转发。隔离 OpenSSH 覆盖带口令 Ed25519、错误口令与错误指纹。
- **注入与目标**：固定脚本内容进行 shell 引号编码，用户 JSON 走 stdin；Python tmux 命令使用参数数组。pane ID 只允许数字标识，控制字符拒绝。用户 `!` 由原 Codex 处理，App 不直接执行；代理的工具输出不能伪装成用户命令结果。
- **消息与 UI**：白名单识别 `UserMessage` / `AgentMessage`，排除 reasoning、response_item、系统/开发者提示和一般 CommandExecution。无 WebView、HTML、远程图片、可执行链接或自动剪贴板动作；文本允许用户主动选中复制。消息仍可能包含 Codex 或用户主动输出的秘密，不能当作 DLP 脱敏工具。
- **手机数据**：私钥/配置用 AES-256-GCM，随机 IV 和 AAD；禁用备份/设备迁移与截图；对话和口令不写磁盘；0.3.0 加密保存执行器身份/阅读书签/待确认标记，草稿可选且默认关闭，使用独立 Keystore alias、AAD 和有界原子文件。关闭草稿选项后仅移除磁盘草稿，当前进程草稿仍可编辑。锁屏/后台断开；密钥与口令使用时会进入进程内存，不抵御失陷设备，部分 JVM 字符串无法可靠清零。
- **下载站**：仅固定三个 GET/HEAD 路由；私网 IPv4 绑定、来源网段、Host 校验、CSP、无上传/命令接口/目录索引；APK 内不包含连接配置或密钥。HTTP 只适用于可信 LAN，校验和不能独立证明来源，禁止转发 8765。
- **仓库**：当前受控文本的私钥头与常见令牌格式扫描未发现匹配；这不是完整密钥扫描，也未证明 Git 历史中的旧值失效。APK、keystore、local.properties 和运行日志由忽略规则排除。
- **依赖**：直接依赖固定版本，Gradle 发行包有 SHA256 校验。核对 [JSch 官方安全页](https://github.com/mwiede/jsch/security) 和 [BC 1.86 发布说明](https://www.bouncycastle.org/resources/new-release-bouncy-castle-java-1-86/)；BC 当前版本含该说明列出的修复。官方页面和版本号不等于全量依赖审计，尚无 Maven 全依赖校验元数据及持续 SCA。

## 0.3.0 增量复核

- 原控制面板缺少 Shift+←、Alt+↓ 和回答输入。现已补齐组合键、自由回答、显式提交与跳过确认；提示识别只用于展示入口，不用于自动批准。普通发送仍拒绝菜单状态。
- 控制操作绑定当前进程/文件身份及手机展示画面；问题或选项变化时拒绝陈旧请求。确认对话框保留打开时的摘要，避免等待确认期间换题后误按。组合键为固定白名单，自由文字走 stdin/random buffer，不拼入 shell；自由回答不自动回车。
- paste/send-keys 开始后异常统一标记结果不确定并禁止重试；写入前先保存加密待确认标记，防止杀进程后丢失风险状态。草稿文本只有用户开启时才落盘。保存失败不会绕过这一步继续发输入。
- 正向游标只推进到完整 JSONL 行；窗口末尾半条记录留给下一次读取。游标越界/文件截短拒绝继续，不切到其他会话。有限内存最多 300 条/会话、8 个会话元数据；超限历史保留在 NAS，由终端核对。
- Markdown 仅原生文字，表格列/行有界；折叠预览不提供可能复制半条命令的代码按钮，展开后按完整代码块复制。没有新增网络权限、监听端口、第三方渲染器或自动链接。
- 仍不能消除“检查后另一端立刻改变输入”的竞争窗口；需要同一时间只在一个终端输入。Android 加密存储、杀进程恢复和 Compose 运行行为尚待真机验证，源码复核不代替设备测试。

## 0.3.1 原生表单复核

原生表单仅适配已验证的异步问题布局，不把任意终端文本或权限审批转换成可一键批准的表单。题目/选项/分页/固定页脚/选中行必须完整匹配；现有电脑端回答、未知布局、截断或超限数据返回手动入口。忽略待答计时变化，保留问题数和题目变化校验。

“提交回答”是新的显式用户操作，允许在同一请求内选择、粘贴并发送一次 Enter；与仍只粘贴的旧控制面板输入区区分。每一步重新核对执行器和当前题目，粘贴后验证显示内容，异常停止且不重试。“稍后回答”只导航返回，不发送 Enter。选项只在手机预选，不自动批准；动画退场中的旧题不可提交。

问题摘要不是官方请求 ID，不能排除相同题面重复出现、TUI 版本变化和检查之后目标变化。共享终端仍非原子输入通道，不能作为强审批隔离协议。0.3.1 原生回答仅单行/4 KiB（0.4.0 扩展为多行）、表单数据最多 8 KiB，超过范围用控制面板；这些限制不改变既有 SSH 权限。

当前题目草稿可按已有开关加密保存，额外保存的只是问题摘要，不保存题目正文；其余问题的选择与草稿只在进程内有界缓存。跨题/分页变化不自动复用，重启后不自动选中或提交。

## 0.4.0 附件与重连复核

- 附件内容通过固定程序的 SSH stdin 传输，JSON 头有界、文件流有界并校验 SHA-256；文件名/文字不插入 shell。发送消息前再次检查当前前台连接与执行器。上传不发送任何 tmux 按键，消息仍使用原有一次粘贴/确认保护。
- NAS 目录/文件要求当前用户独占，使用 `O_NOFOLLOW`、目录描述符和随机临时文件；仅普通文件可引用。最终链接不覆盖既有文件，重复 ID 只能复用内容完全相同的附件。全局有界扫描及目录锁控制 256 文件/256 MiB 配额；部分写入失败清理，进程强制终止后可能留有计入配额的临时文件。
- 手机按读取中的实际字节数限制附件总量，不信任提供者声明的大小；只复制用户明确选择的 URI，不申请全盘权限、不保留持久 URI 授权、不把附件加入加密草稿。临时副本位于私有 cache，明确移除/发送完成/换会话/下次进程启动清理。缩略图在 IO 线程按最长边采样至约 192 像素，不自动抓取远端图片。
- 附件路径属于当前执行器绑定，拒绝跨会话引用、符号链接、校验变化及命令混用。不自动执行上传文件，但给 Codex 的“不执行”说明不是沙箱；仍由用户、当前会话权限及 NAS 用户权限形成边界。文件保留于 NAS 供任务继续读取，用户需按需清理。
- 读取失败才允许前台有限重连，指纹与公钥认证保持原规则，恢复输入前核对 pane/绑定。写入结果不确定时不进入此路径。系统选择器是显式、限时的生命周期例外：SSH 暂停，但解锁身份最多留内存 120 秒；选择器内锁屏也受此上限约束，普通后台仍清除。无口令持久化或后台服务。
- 多行回答仍拒绝除换行以外的 C0/C1 控制字符；空行/视觉折行核对后一次确认，题面截断或变化停止。权限审批不转换为此表单。附件卡片只是公开消息的显示转换，不能触发文件读取或网络请求。
- 未发现新增公网监听、指纹绕过、任意路径覆盖或输入自动重放路径。此次为源码与隔离测试复核，Android 生命周期和文件提供者异常仍需真机检验；没有进行全依赖漏洞扫描或生产渗透测试。

## 0.4.1 选择器与相机增量复核

选择器回调移动到应用根部，超时断开不会注销结果接收；附件目标与传输 epoch 分离，复制文件也不因 SSH 重连中断。恢复列表按主机/用户/指纹与 pane 身份筛选，发送还必须匹配原 Codex 绑定；清除资料或切换主机使进行中的选择失效。两分钟后仍清除解锁身份，没有延长后台认证材料保留时限，也没有自动发送。

Photo Picker 仅取得用户明确选择的图片；系统相机使用临时 URI、非导出的专用 FileProvider，路径只覆盖 `cache/camera/`，不覆盖凭据、一般附件目录、外部存储或整个 cache。拍照返回复制后/取消后清理文件并撤销 URI 授权，没有新增 CAMERA、READ_MEDIA_IMAGES 或外部存储权限。应用进程被杀后的附件恢复仍未实现，真实设备相机与生命周期回调尚待验收。

表格取消弹框和短行折叠，保留解析上限与只显示文字的边界，不引入 WebView 或图片自动网络加载。

- 22 项 Kotlin/JVM 测试：新增 4 项附件重连恢复与跨主机/窗格/执行器拒绝测试；表格新增转义/代码竖线/对齐/列数不匹配；真实 loopback SSH 扩展暂停/重新认证与 1 MiB 附件内容一致性；新增连接错误分类和显示用 Markdown 解析；原有覆盖包括输入/指纹/身份校验、隔离 tmux、临时 loopback OpenSSH。无跳过。
- 3 项 HTTP 测试：内容/校验和、HEAD、路径遍历和方法拒绝、来源/绑定/Host 边界。
- 真实隔离 Codex 0.154.0 验证 `!printf`、`/status`、中文多行、换行与长文本折叠显示；0.3.0 再验证两道异步问题的打开/切换、Other 中文回答、返回主输入框及选择项提交，Codex 最终确认收到两项回答。0.4.0 在同一隔离 Codex 会话中实际查看上传的红蓝图片、读出文本测试词，并通过原生提交接口一次提交含空行的 Other 回答。未向当前生产对话输入测试文字。
- Debug、Release 与 Lint 通过；无已连接 Android 设备，因此未实际验证本版的 UI、Keystore 行为、网络切换和帧率。
