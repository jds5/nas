# 接续 · NAS Remote

独立 Android 子项目：通过 SSH 接续 NAS 上正在运行的 Codex。当前为 0.4.0，默认展示聊天消息，普通输入框一次发送；原终端模式保留为可选入口。无需新端口或 NAS 常驻服务，不新建、恢复或分叉正在控制的 Codex。

## 结构

```text
apps/android/
  app/                 # Compose 界面、连接生命周期、Keystore 凭据存储
  core/                # JVM SSH/tmux 传输、安全测试
    src/main/resources/nas_remote_bridge.py  # 随包分发、通过 SSH 执行的无状态适配器
    src/test/python/   # 消息过滤、输入保护、真实 tmux / proc 测试
  distribution/        # 仅 LAN 的 APK 下载页面
  gradle/wrapper/       # 固定 Gradle 版本与发行包校验
```

不增加账户系统、云端服务、数据库或后台保活服务。`app` 依赖 `core`；协议层不依赖 Android。未来确有需要再拆模块。

## 构建与安装

需要 JDK 17、Android SDK Platform 37.0、Build Tools 36.0.0。设置 `ANDROID_HOME` 或在本目录的 `local.properties` 写入 `sdk.dir=SDK绝对路径`，文件已忽略。

```bash
cd apps/android
./gradlew :core:test :app:assembleDebug :app:lintDebug
# Linux 上额外运行隔离的真实 tmux 测试，需要 tmux 和 /usr/bin/python3
NAS_TMUX_TESTS=1 ./gradlew :core:test --rerun-tasks
# 另有本机 /usr/sbin/sshd 时，可加入临时 loopback SSH 认证测试
NAS_TMUX_TESTS=1 NAS_SSH_TESTS=1 ./gradlew :core:test --rerun-tasks
NAS_TMUX_TESTS=1 python3 -m unittest discover -s core/src/test/python -v
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

支持 Android 9（API 28）及以上，目标 Android 17（API 37）。Debug APK 仅用于个人测试；正式版本需单独管理发布签名，私钥和签名资料不入库。

依赖固定版本：AGP 9.4.0、Gradle 9.6.0、Kotlin 2.4.20、Compose BOM 2026.09.00、Material 3 1.4.0、JSch 2.28.7、Bouncy Castle 1.86。Material 3 使用当前稳定发布，不引入 alpha 组件；使用公开的 Compose 弹簧动画、动态配色、深色主题、页面与列表过渡。依赖版本依据及本轮验证见下文。

## 外网使用前提

本 App 主要用于在外部网络连接本仓库所在的 NAS，本机就是 SSH/tmux 目标。支持公网 IP / DNS-only DDNS＋自定义外部 SSH 端口；VPN 可选，不是必须先安装的条件。现有 HTTPS 业务入口不能直接替代原生 SSH 转发。Android 17 的局域网权限不再阻止公网连接，使用内网地址时按需授权。

公网入口、本机信息与完整密钥配置步骤见 [外网连接手册](../../docs/operations/手机外网连接与SSH密钥配置.md)。局域网获取测试 APK 可打开 **http://192.168.50.33:8765/**，服务说明见 [distribution](distribution/README.md)。

## 首次连接

1. 在可信电脑上为手机创建独立 SSH 密钥，例如 `ssh-keygen -t ed25519 -f nas-phone`，设置私钥口令；按现有 NAS SSH 管理流程授权 `nas-phone.pub`。授权的 Unix 用户必须能访问目标 tmux 默认 socket。不要导入日常管理员的通用私钥。
2. 从可信 NAS 终端执行 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256` 核对主机指纹。填写完整 `SHA256:...`，不含末尾注释；不要只通过未经核验的 `ssh-keyscan` 建立信任。
3. 将手机专用私钥通过可信路径转移至手机，在 App 导入。连接成功后 App 加密保存副本；确认可用后自行清理传输副本。口令每次连接输入，不保存。
4. 填入主机、端口、SSH 用户及指纹。外网填写已验收的公网主机和路由器外部 SSH 端口；Android 17 仅在访问内网地址时按需授权。App 不负责路由器转发或 VPN 配置。
5. 点击 Codex 会话默认进入聊天页，编辑后点“发送”。输入 `/` 选择命令，`/skills` 打开技能列表，选择技能插入 `$技能名`；`!命令` 在 NAS 的 Codex 中执行。Codex 提问时点击问题卡片，选择选项或填写自定义回答，再点“提交回答”；菜单、审批或核对已有草稿可打开“控制面板”。列表及顶部的“终端”保留原先的粘贴、回车操作；其他程序仍只读。
6. 前台短暂断网会尝试接回原执行器（最多 3 次），保留当前阅读与输入且不重放任何发送。离开 App 或锁屏会关闭 SSH；远端任务继续。返回后可点“接回上次会话”，有私钥口令时仍需输入；原执行器变化则停止。电脑和手机共享输入，请避免同时操作。

使用默认 tmux socket，远端需要 POSIX shell、PATH 中的 tmux（已在 3.5a 验证）。聊天模式另外需要 Linux `/proc`、Python 3.9+ 以及同一 Unix 用户可读取的运行中 Codex rollout 文件（本次验证 CLI 0.154.0）。不支持跳板、密码登录、SSH 配置文件和自定义 socket。连接需有正在运行的 tmux server。填写的指纹必须与 SSH 实际协商的主机密钥匹配；指纹变更时拒绝连接，需通过可信渠道重新核对。

## 安全边界

- 仅公钥认证，强制固定 SHA256 主机指纹；保留 SSH 库默认算法限制，不自动接受未知主机。
- 私钥副本与连接配置使用 Android Keystore AES-256-GCM 加密，存于不备份目录；禁用应用备份与截图。私钥在连接时仍需进入应用内存，Keystore 不等于硬件内 SSH 签名；不抵御已经失陷的手机或 NAS。
- 不持久化对话输出、私钥口令或连接日志。用户主动选择的附件暂存于应用私有 cache，发送成功、移除、切换会话或下次进程启动时删除；不是加密草稿，也不保存系统文件的长期访问授权。最多 8 个会话的执行器身份、阅读位置和发送结果标记加密保存；草稿默认仅在内存，可在连接页开启“加密保存草稿”，包含普通输入和自由回答草稿。使用独立 Keystore 密钥、AES-GCM 与原子文件，文件上限 2 MiB；关闭选项后删除磁盘记录中的草稿，清除本机资料会同时删除这些记录。普通编辑以 300 ms 防抖保存，突然杀进程可能丢失最后一次编辑。
- 输入通过 SSH stdin → 随机命名 tmux buffer 传递，不拼入 shell 命令；拒绝终端控制字符，单次最多 16 KiB。发送前校验 pane ID、pane PID、server PID、存活与前台命令；目标变化则失败，不自动创建替代会话。
- 检查与发送并非操作系统级原子操作，不能保证目标恰在检查后退出时绝对不会落入其他程序；tmux 和当前 Unix 用户本身属于信任边界。命令名也不是程序签名认证。
- 写入结果不确定时立即断开，禁止自动重试；重连、读取窗格并手动确认后恢复操作。Ctrl-C 需二次确认。按钮成功只表示终端输入已发送，不代表任务执行成功。
- 输出使用原生文字组件，可选择复制，支持标题、列表、粗体、行内代码、代码块和横向滚动表格（每块最多 12 列/200 行，超限部分原文显示）；不执行 ANSI/OSC、HTML、链接或远端剪贴板动作，不加载远程图片。SSH 单次响应上限 256 KiB；聊天每次扫描至多 1 MiB，返回至多 80 条/约 180 KB 消息，单条上限 24,000 字符，App 内至多 300 条；终端显示约 400 行。
- App 限制不是服务器权限隔离：手机持有的 SSH 密钥仍具有该 NAS 用户的权限。遗失手机后应在 NAS 撤销对应公钥；“清除本机资料”不会撤销服务器授权。

## 体验与当前限制

默认聊天模式按所选 pane 的进程树找到 **该 Codex 进程正在打开的会话文件**，用进程启动时间、文件 inode 和会话 ID 绑定；不按目录或“最新文件”猜会话。每秒读取已落盘的公开用户消息、Codex 进展和最终回复，排除内部推理、系统/开发者提示、代理工具日志。只有用户主动 `!` 执行的命令结果作为独立消息显示。

“发送”在同一 SSH 操作内完成 bracketed paste 与 Enter，先核对原执行器和电脑端空输入框，再核对粘贴结果。支持中文、多行、换行及长文本折叠卡片；无法识别的界面、已有草稿或会话变化会拒绝盲目回车。粘贴后状态不确定则保留草稿、断开连接，重连核对后恢复，不能直接再次点发送。电脑和手机不能同时输入；这些检查不是输入锁。

- `/` 提供常用命令建议，也能输入其他原生 Codex 命令；发送后打开真实终端控制面板，通过方向键、Tab、确认和 Esc 操作。支持 Shift+← 打开/切换待答问题、Alt+↓ 上一题/返回、Other 自由回答及 Ctrl+] 跳过（需确认）。权限确认不自动同意，不伪造审批卡片。
- `/skills` 浏览 NAS 上有界扫描得到的 SKILL.md 名称和说明，选择后使用 Codex 原生 `$技能名`；实际加载、同名技能和插件可用性以当前 Codex 会话为准。可选择“打开 Codex 原菜单”。
- `!` 原样交给 Codex 的 shell 模式，沿用当前 Codex 权限；不经桥接直接执行用户 shell 文本。命令在 NAS 上运行，不是手机本地命令。
- 这是当前 CLI 的适配层，**不是官方 Remote Control / App Server 协议**。消息在 Codex 写入完成事件后出现，不支持逐 token 流式输出；没有可靠事件的菜单状态仍在控制面板查看。
- 从未产生过记录的新会话、其他 CLI 版本或无法唯一关联的文件会提示使用终端模式。先在原终端产生一轮记录，再返回列表重新打开即可尝试聊天模式。
- 单条超过显示上限、超过 300 条历史、超过 1 MiB 的单条 JSON 记录或无法识别的界面需要终端核对。退出 App 后聊天内容不保存在手机；NAS 自身的 Codex 日志保留策略不受 App 控制。

界面沿用稳定版 Material 3、动态配色和系统动画设置；聊天使用稳定消息 ID、惰性列表、轻量原生 Markdown 显示和列表过渡，网络与文件操作在 IO 线程。未连接 Android 真机/模拟器，不能宣称达到 60/90/120 Hz；本版仍需实机验证输入法、旋转、字体缩放、锁屏换网以及发送期间断网。

## 0.4.0：附件、阅读与接续（2026-09-17）

- **图片与文件**：聊天输入区点“＋ 图片 / ＋ 文件”，通过系统选择器选择，检查缩略图/名称/大小，需要时移除，再点一次发送。最多 4 个，总量 20 MiB；不申请全盘存储权限。支持图片识别与缩略图的格式为 PNG/JPEG/WebP，其他格式按普通文件交付。上传显示进度，发送后显示附件卡片；复制原消息仍包含 NAS 路径。
- **交付方式**：使用现有、固定指纹的 SSH 流式上传，校验大小和 SHA-256。上传完毕才把 NAS 文件路径及说明送给**同一个运行中的 Codex**。图片由该会话的图片工具读取；文件是否能解析、是否需要权限取决于当前 Codex 的工具与沙箱。不是直接给模型注入原生多模态输入，没有启动第二个执行器。测试已实际查看图片并读取文本。
- **私有存储**：NAS 路径为 `~/.nas-remote-uploads/`（0700），文件为 0600；文件名由会话绑定摘要和随机 ID 组成，不使用手机原文件名作为路径。拒绝符号链接、权限异常、错误校验值、跨会话引用和上传中目标变化。目录总量限制 256 MiB / 256 文件，上传锁串行核对配额；传输限时 120 秒，正常失败移除部分文件。崩溃残留计入配额。不自动删除已交付附件，以免正在运行的任务或历史引用失效。
- **阅读**：表格有可读列宽、横向滚动提示/位置条、左右按钮、交替行底色、列对齐及展开阅读。正文内预览最多 8 行，可展开查看全部；支持转义竖线和行内代码中的竖线。长消息预览保留 Markdown，预览中的代码须展开后才能按代码块复制。没有 HTML/WebView 或自动加载远端图片。
- **回答**：自由回答支持多行与空行（上限仍为 4 KiB），原生表单显示提交结果；清除已提交问题的预选与缓存，重连时禁用提交。未知或截断的题面仍需控制面板核对。
- **前台接续**：只在读取失败、没有进行中的写入且没有待核对结果时尝试重连；间隔 1/2/4 秒、最多 3 次，每次仍核验服务器指纹、公钥认证、原 pane 和原 Codex 绑定。指纹/认证拒绝或会话替换直接停止。成功后按原游标补读，不自动重发输入或附件。
- **选择器生命周期**：进入系统文件选择器时暂停 SSH，仅在内存中短时保留已经解锁的身份，最长 120 秒；返回后重新认证和核对原会话。超时需手动解锁重连。不保存私钥口令，不增设后台服务。普通退后台/锁屏仍清除连接中的解锁身份；在选择器内锁屏也受该 120 秒上限约束。

附件若与 `/` 或 `!` 命令混用会拒绝发送。任何发送中断都不会自动重放；保守地进入待核对流程，上传成功不代表 Codex 已接收或已处理。手机暂存和 NAS 附件目录不属于 APK 下载页，不能通过该页面访问。

清理 NAS 附件前，先核对列表和仍被任务引用的文件：

```bash
ls -lah -- ~/.nas-remote-uploads/
du -sh -- ~/.nas-remote-uploads/
# 确认具体文件不再需要后，只删除对应文件；不会连带删除手机原文件。
# rm -- "$HOME/.nas-remote-uploads/<已经核对的具体文件名>"
```

阅读设计参考 [compose-table 的整表横向滚动与最小列宽](https://github.com/windedge/compose-table)、[multiplatform-markdown-renderer 的 Compose 分块渲染](https://github.com/mikepenz/multiplatform-markdown-renderer)，沿用本项目轻量原生组件，没有引入这两个库或复制其源码。

43 项 Python、18 项 JVM、3 项下载服务测试，以及 Debug/Release/Lint 通过。验证包含隔离真实 Codex 0.154.0：同一会话查看上传图片、识别左右红蓝颜色、读取文本测试词、多行 Other 回答的空行原样复述；临时 loopback SSH 验证暂停后重新认证、1 MiB 附件流式传输与逐字节一致性。Android 系统选择器、缩略图、软键盘、表格手势及 Wi-Fi/4G 切换仍待真机验收，不宣称已测帧率。

## 0.3.1：原生问题表单（2026-09-17）

聊天页的待答卡片进入 Material 3 表单，显示完整题目、可点选选项、“自定义回答”和“提交回答”。没有预设选项时直接显示回答输入框；多题用“上一题 / 下一题”，不需要记快捷键、粘贴或手动回车。“稍后回答”保留问题并返回聊天输入；直接收起表单只隐藏手机表单，再发聊天消息时会提示先返回聊天。

- 点击选项只改变手机选择，不立即提交；明确点“提交回答”后，适配器核对问题/会话、逐步核对选项移动、核对自由文字，最后仅发送一次 Enter。任何中途变化停止；可能已操作时按原有流程重连核对，不重放。
- 只转换当前 CLI 能完整识别的异步问题布局；截断、已有电脑端自由回答、未知布局、超过 8 KiB 的题目/选项数据使用控制面板。权限审批不套用此表单。0.3.1 自定义回答支持单行、最多 4 KiB（0.4.0 已支持多行），复杂输入保留手动入口。
- 问题身份是当前画面的摘要，不是官方请求 ID。题目、选项或分页变化会失效；即使内容完全相同也无法消除共享终端的竞争窗口，不支持电脑与手机同时输入。
- 原生回答草稿按会话和问题摘要隔离；进程中最多缓存 32 个问题的选择/文字。开启加密草稿时仅保存当前问题草稿与摘要，选择不会在进程重启后自动勾选。剩余题数变化后按新问题处理，避免套用其他题的草稿。

隔离真实 Codex 已验证切题、点选等价接口的一次提交、中文自定义回答的一次提交，Codex 回复确认收到两项回答；另验纯文本问题与长中文换行。33 项 Python、16 项 JVM、3 项下载服务测试，以及 Debug/Release/Lint 通过；没有连接 Android 真机，表单布局、软键盘与动画仍待实机验收。

## 0.3.0：回答问题与断线接续（2026-09-17）

- **回答问题**：识别当前 CLI 的待答提示后，聊天页显示入口；即使没有识别提示，也可手动打开控制面板。点“打开 / 下一题 ⇧←”，用 ↑↓ 选择，点“确认 ↵”。自由回答先选择 Other，在独立输入框输入并点“填入回答”，核对原界面后点确认；支持返回/上一题、左右移动、退格、清行和跳过。普通聊天仍是一次发送，回答面板保留核对步骤。
- **操作保护**：确认、按键和填入回答携带手机所见画面的摘要，再核对执行器；画面变化拒绝旧操作。已识别的异步问题只比较完整问题区，避免后台进度动画阻断回答；其他菜单比较全屏。每次写入前先加密保存待确认标记，成功后清除；不确定结果不自动重发，重启后仍需核对。不是终端输入锁，勿与电脑同时操作。
- **发送与草稿**：显示“正在发送”“已提交到 Codex 输入端”“未发送/待核对”；不把 tmux 接收等同于模型已接收或任务成功。可选加密草稿，按主机、公钥指纹、用户与原执行器隔离。
- **接回原会话**：连接页提供“接回”；重新认证并核对原 pane 和 Codex 绑定，恢复阅读位置/草稿，按完整 JSONL 记录边界向前补读。手机进程仍在时用内存游标；进程重启后从加密书签重新读取 NAS 记录。后台仍断开 SSH，不保存私钥口令，不自动重放输入。
- **阅读**：简单表格横向滚动、消息/完整代码块复制、长输出折叠、未读提示与返回最新。阅读旧消息时不因新回复自动跳走。超过单条/300 条缓存上限仍需终端核对，不承诺无限历史同步。聊天正文不落盘。

实测依据：隔离的真实 Codex CLI 0.154.0 发起两道异步问题，经桥接打开/切题、选择 Other、填入中文自由回答、返回主输入框、选择另一选项并提交，Codex 回复确认收到两项回答；没有向当前生产会话发送测试按键。其余验证与待验收项见 [安全诊断](../../docs/security/ANDROID_APP_SECURITY_REVIEW.md)。手机仍需实测键盘、进程重启、断网及滚动帧率；当前没有真机测量证据。

## 0.2.1 连接诊断（2026-09-16）

将原来统一的“SSH 连接失败”拆为可反馈的错误编号：域名解析 `E_DNS`、系统网络权限 `E_NETWORK_DENIED`、TCP 超时/拒绝/路由错误、SSH 握手、公钥认证与主机指纹错误。TCP 阶段通过实际创建连接记录，指纹通过后才标记认证阶段；不额外探测、不保存网络日志，也不展示原始异常、私钥或口令。

该版本是诊断改进。随后通过 `E_TCP_TIMEOUT`、NAS 抓包与 UFW 规则定位到服务器仅允许 LAN SSH；提供指定接口/IPv4/22 的允许规则后，2026-09-17 用户反馈 4G 连接恢复。恢复证据来自用户实测，助手未代执行防火墙修改，详见运维记录。后续功能提案见 [手机接入规划](../../docs/operations/手机接入现有tmux规划.md)。
